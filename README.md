# Simple Rule-Based Chatbot

This is a simple rule-based chatbot built using Python. It can respond to basic user messages such as greetings, asking how it is, and saying goodbye.

## Features

* Responds to greetings like "hello" and "hi"
* Responds to "how are you"
* Responds to "bye"
* Uses if-elif statements
* Uses functions and loops
* Takes input from the user

## Technologies Used

* Python

## How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in the terminal.
3. Run the following command:

```bash
python chatbot.py
```

## Example

```text
Chatbot: Hi! Type 'bye' to exit.

You: hello
Chatbot: Hi!

You: how are you
Chatbot: I'm fine, thanks!

You: bye
Chatbot: Goodbye!
```

## Project Purpose

The purpose of this project is to practice basic Python concepts such as functions, if-elif statements, loops, string handling, and user input/output.
